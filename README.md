## 🔎 Overview

The **Neon Vocabulary Builder** is a **futuristic, animated, glowing** web app designed to make English vocabulary learning **smooth, fun, and ultra-modern**.  
With a ✨ neon interface, 🎞️ soft animations, and a 🧼 clean layout, this project turns vocabulary practice into an **engaging digital experience**.

---


## 🚀🛠️ Tech Stack

- 🧩 **HTML**  
- 🎨 **CSS**  
- ⚙️ **JavaScript**

Fast • Lightweight • Framework-free ⚡

---

## ✨ Features

- ⚡ **Neon UI with glowing effects**
- 📘 **Vocabulary cards with meaning & usage**
- 🎬 **Animated background for premium aesthetics**
- 📱 **Fully responsive layout**
- 🚀 **Fast, lightweight, no frameworks**
- 🧠 **Beginner-friendly UI**
- 🎨 **Easily customizable (words, colors, animations)**
